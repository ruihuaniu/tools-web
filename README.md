## 🚀 Quick Start

Each tool is standalone and can be accessed independently:

```bash
# Navigate to any tool directory
cd finance-calculator

# Install dependencies (if applicable)
npm install

# Run the development server
npm start
# or
npm run dev
```

### For Next.js Projects (Healthcare)

```bash
cd health-care
npm install
npm run dev
```

The application will be available at `http://localhost:3000`
